# Java class skeleton

## Code

```defaults
// Default: plain Java class, no Javadoc
```

```java
package ${packageName};

public class ${className} {
}
```

## Variables
| Variable | Source | Default |
|----------|--------|---------|
| `${packageName}` | existing DTO package in the project, or `${rootPackage}.dto` | -- |
| `${className}` | user choice | `${EntityName}Dto` |
