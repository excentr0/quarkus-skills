# Migration file

## File

Flyway:

```text
src/main/resources/db/migration/V${version}__${description}.sql
```

Liquibase:

```text
src/main/resources/db/changelog/changes/${changesetFile}.xml
```

The exact directory and file-name pattern must match the project's existing migrations
(see `SKILL.md` Step 1) — the paths above are the conventional shape, not a guarantee.

## Code

### Flyway — CREATE TABLE (PostgreSQL / H2)

```sql
-- ${description}
CREATE TABLE ${tableName} (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    ${columnName} ${columnType} NOT NULL,
    ${fkColumn} BIGINT NOT NULL,
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT fk_${tableName}_${referencedTable} FOREIGN KEY (${fkColumn})
        REFERENCES ${referencedTable} (id)
);

CREATE INDEX idx_${tableName}_${fkColumn} ON ${tableName} (${fkColumn});
```

### Flyway — CREATE TABLE (MySQL / MariaDB)

```sql
-- ${description}
CREATE TABLE ${tableName} (
    id BIGINT NOT NULL AUTO_INCREMENT PRIMARY KEY,
    ${columnName} ${columnType} NOT NULL,
    ${fkColumn} BIGINT NOT NULL,
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT fk_${tableName}_${referencedTable} FOREIGN KEY (${fkColumn})
        REFERENCES ${referencedTable} (id)
);

CREATE INDEX idx_${tableName}_${fkColumn} ON ${tableName} (${fkColumn});
```

If the project already has tables, **copy the id/column style of an existing migration** instead of
picking a variant — that keeps the schema consistent.

### Flyway — ALTER TABLE (add column)

```sql
-- ${description}
ALTER TABLE ${tableName}
    ADD COLUMN ${columnName} ${columnType} ${nullableClause};
```

`${nullableClause}` is `NULL` for a new optional column; for a required column on a populated table:
add it `NULL`, backfill in the same migration, then `ALTER COLUMN ${columnName} SET NOT NULL`
(PostgreSQL) — or use the project's established pattern.

### Flyway — index only

```sql
CREATE INDEX idx_${tableName}_${columnName} ON ${tableName} (${columnName});
```

### Liquibase — changeset (create table + index)

```xml
<?xml version="1.0" encoding="UTF-8"?>
<databaseChangeLog
        xmlns="http://www.liquibase.org/xml/ns/dbchangelog"
        xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
        xsi:schemaLocation="http://www.liquibase.org/xml/ns/dbchangelog
                            http://www.liquibase.org/xml/ns/dbchangelog/dbchangelog-latest.xsd">

    <changeSet id="${changesetId}" author="${author}">
        <createTable tableName="${tableName}">
            <column name="id" type="BIGINT" autoIncrement="true">
                <constraints primaryKey="true" nullable="false"/>
            </column>
            <column name="${columnName}" type="${columnType}">
                <constraints nullable="false"/>
            </column>
            <column name="${fkColumn}" type="BIGINT">
                <constraints nullable="false"
                             foreignKeyName="fk_${tableName}_${referencedTable}"
                             references="${referencedTable}(id)"/>
            </column>
        </createTable>

        <createIndex indexName="idx_${tableName}_${fkColumn}" tableName="${tableName}">
            <column name="${fkColumn}"/>
        </createIndex>
    </changeSet>

</databaseChangeLog>
```

Add the new file to the changelog with an `<include>` in the right position
(see `references/liquibase.md` §5) — or append the `<changeSet>` to the existing changelog file when
the project keeps one file.

## Variables

| Variable | Source | Default |
|----------|--------|---------|
| `${version}` | max existing migration version + 1 | -- |
| `${description}` | the change, matching existing file names | `snake_case` description |
| `${tableName}` | entity `@Table(name=...)` or the request | -- |
| `${columnName}` | entity `@Column(name=...)` or the request | -- |
| `${columnType}` | entity field JDBC type | -- |
| `${fkColumn}` | the FK's owning column | -- |
| `${referencedTable}` | the referenced table | -- |
| `${nullableClause}` | column nullability | `NULL` for new optional columns |
| `${changesetFile}` | project's changeset naming | `NNN-${description}.xml` |
| `${changesetId}` | next id in the changelog | `NNN` or a project pattern |
| `${author}` | existing changesets' author value | project's git user |
